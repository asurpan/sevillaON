# 📘 MANUAL DE OPERACIONES - RADIO ON AIR (PROTECTED CORE)

Este manual es de lectura OBLIGATORIA para cualquier IA o Agente que retome este proyecto.

## 🏗️ ARQUITECTURA (CLEAN MODULES)
El motor web ha sido refactorizado en archivos independientes para una claridad total:

1. **RadioPersistence.kt**: Gestiona localStorage y carga de estado inicial.
2. **RadioNetworkManager.kt**: Único punto de contacto con Firebase (Chat, Users, Inbox).
3. **RadioAudioManager.kt**: Motor de AudioContext, WebRTC (PeerJS) y PTT.
4. **RadioBridge.kt**: Puente de eventos JS -> Compose UI.
5. **main.kt**: Punto de entrada y coordinación de la interfaz.

## ⚠️ REGLAS DE ORO
- **SEGURIDAD**: Cada Nick está vinculado al ID del teléfono (Hard-Lock). No permitir el cambio de Nick si ya existe un registro.
- **PTT**: El botón PTT debe ser libre y reactivo. Los LEDs de portadora deben encenderse SIEMPRE al pulsar.
- **VISIBILIDAD**: Mantener el sistema de "Frecuencia Única" (Nuclear Option) en `main.kt` hasta que la red sea estable.
- **DESACOPLAMIENTO**: No mezclar lógica de audio en el NetworkManager ni viceversa.

## 🚀 DESPLIEGUE
- El despliegue es automático vía GitHub Actions (25 min).
