PROTOCOLO DE PRIVACIDAD V11.0 (PURE RADIO)

Resumen para el usuario: Nuestra aplicación es una emisora de radio digital. No rastreamos tu identidad real, no pedimos tu número de teléfono y no guardamos grabaciones de voz. Tu privacidad es nuestro núcleo técnico.

1. RECOPILACIÓN Y USO DE DATOS

En cumplimiento con las políticas de Google Play, informamos que ON AIR SPAIN minimiza la recopilación de datos al máximo estrictamente necesario para la función de radio:

  • Ubicación Aproximada (IP): No solicitamos el permiso de ubicación de grano fino (GPS). Estimamos tu provincia mediante la dirección IP exclusivamente para conectarte de forma automática a la frecuencia local correspondiente.
  • Indicativo de Radio: Solicitamos un nombre de usuario (Indicativo) para identificarte en la red. Este nombre es efímero y puede ser modificado por el usuario en cualquier momento.
  • Estado de Conexión: Transmitimos tu estado (en línea/hablando) para que otros usuarios en el mismo canal puedan interactuar contigo.

2. PERMISOS DE HARDWARE CRÍTICOS

Para el correcto funcionamiento de la emisora, la aplicación requiere:

  • Micrófono (RECORD_AUDIO): Esencial para la transmisión de voz. La aplicación solo accede al micrófono cuando el usuario pulsa voluntariamente el botón PTT o activa la función manos libres (VOX). El audio se procesa en tiempo real y nunca se almacena en el dispositivo ni en servidores externos.
  • Internet: Necesario para la transmisión de datos punto a punto y la sincronización con Firebase.

3. SEGURIDAD Y ALMACENAMIENTO

Utilizamos Google Firebase para la gestión de la red en tiempo real. Los datos de sesión se eliminan automáticamente cuando el usuario cierra la aplicación o tras un breve periodo de inactividad (15 segundos). No compartimos bases de datos con terceros.

4. PUBLICIDAD (Google AdMob)

Para mantener el servicio gratuito y nacional, mostramos anuncios mediante Google AdMob. Google puede utilizar identificadores publicitarios anónimos para la personalización de anuncios, sujetos a la propia política de privacidad de Google.

5. DERECHOS DEL USUARIO

Al no existir cuentas de usuario permanentes (correos o contraseñas), el usuario ejerce su derecho al olvido simplemente cerrando la sesión o desinstalando la aplicación. Todos los datos temporales vinculados a su sesión desaparecerán del nodo nacional.
